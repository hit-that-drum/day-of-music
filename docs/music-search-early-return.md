# 대체 국가 검색 조기 반환 개선

2026-09-07. 이번 비교의 이전 버전은 최초 HEAD 코드가 아니라 **통합 검색 도입 후, Promise.all을 사용하던 직전 코드**다. `scripts/fixtures/music-search-before-early-return.ts.txt`에 보존했다.

## 변경

선호 국가 조회는 유지하고, 대체 국가들을 병렬 조회해 **결과가 있는 첫 응답**을 반환한다. 나머지 요청은 AbortController로 취소한다. 빈 결과나 실패가 먼저 와도 검색을 종료하지 않는다. 모두 실패하면 502, 정상 응답에 결과가 없으면 빈 목록, 사용자 요청 취소는 408을 반환한다.

대체 국가 응답의 US→JP→GB 병합을 없앴으므로 먼저 성공한 국가에 따라 결과 구성은 달라질 수 있다. 이미 시작한 요청은 취소해도 공급자의 호출량에 포함될 수 있다. 선호 국가의 최초 응답 대기는 아직 남는다.

## 실제 API 측정

KR, limit=8, 세 검색어, 버전별 2회. 버전 실행 순서를 교차하고 실행 사이 10초 간격. Node에서 실제 핸들러 및 iTunes 네트워크 호출을 실행했다. Next.js/브라우저 캐시와 렌더링은 제외했으며 공급자 캐시, 네트워크 지연은 통제하지 못했다.

| 검색어 | 직전 1회 | 개선 1회 | 직전 2회 | 개선 2회 |
|---|---:|---:|---:|---:|
| NewJeans | 0.658초 | 1.034초 | 0.072초 | 0.175초 |
| 자몽살구클럽 | 2.950초 | 0.097초 | 8.006초 (502) | 1.503초 |
| Radiohead Creep | 0.120초 | 0.052초 | 0.201초 | 0.054초 |

개선 버전 6회 모두 HTTP 200으로 결과를 반환했고 JP/GB의 미완료 요청을 취소했다. 직전 버전은 1회 모든 국가가 타임아웃되어 502를 반환했다. 공급자 응답 상태가 서로 달랐기 때문에 실패를 포함한 평균을 성능 개선율로 제시하지 않는다.

KR의 지연은 31ms~4초로 큰 편차가 있었다. NewJeans는 개선 후 전체 시간이 더 길어진 회차도 있다. 따라서 이 표본으로 전체 검색이 항상 빨라진다고 결론 내릴 수 없다. 개선 버전에서는 US가 결과를 반환한 뒤 JP/GB를 기다리지 않는 동작을 실제 호출에서도 확인했다.

## 검증

- 타입 검사와 변경 파일 ESLint 통과.
- 기존 검색 회귀 테스트 통과.
- 느린 두 지역이 취소 전까지 응답하지 않는 모의 상황에서, 다른 지역 결과만으로 500ms watchdog 전에 반환하는 테스트 통과. 이 500ms는 테스트 한도이며 실제 API 성능 수치가 아니다.
- 느린 요청 취소, 빈 응답/오류가 먼저 오는 상황, fallback 중 사용자 취소 검사 통과.
